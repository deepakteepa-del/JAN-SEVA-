# JAN-SEVA-
Jan Seva is a citizen complaint management app that helps people report public issues, track complaint status, upload photos and documents, and connect with government officers. It includes AI assistance, location-based complaint reporting, helpline support, and real-time updates. Built using Flutter (Dart) and Supabase.
